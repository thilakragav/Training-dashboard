## 🚀 Key Architectural Highlights & Interactive Engines

### 1. Dual Orbital Animated Core (`HeroVisualizer.tsx`)
- Canvas & SVG interactive visualizer demonstrating the harmonic relationship between **Academy (Learning Stream)** and **Digital Solutions (Engineering Stream)** with real-time toggleable data flows.

### 2. Interactive Technology Constellation (`TechnologyConstellation.tsx`)
- 6-domain interconnected network graph allowing visitors to explore technology nodes (Spark, Fabric, LLMs, Agents, UiPath, Azure, Kubernetes) and immediately reveal associated Academy courses and enterprise consulting capabilities.

### 3. 4-Step Career Pathway Discovery Engine (`LearningPathFinder.tsx`)
- Algorithmic recommendation advisor evaluating background (Student, Developer, QA, Non-Tech), interests, goals, and weekly commitment to recommend calibrated learning sequences and pathways out of 14 covered roles.

### 4. Enterprise Solution Discovery Engine (`SolutionDiscoveryEngine.tsx`)
- B2B project generator matching enterprise operational challenges (Legacy ETL bottlenecks, manual document entry, ungrounded LLMs) to recommended architecture blueprints and delivery timelines.

### 5. Multi-Domain Tech Stack Matrix (`TechStackExplorer.tsx`)
- Interactive filterable grid highlighting NodalBot's production technology competencies across Data Engineering, BI, AI/ML, Cloud, Automation, and DevOps.

### 6. Dynamic Upcoming Batches Scheduler (`UpcomingBatchesSection.tsx`)
- Real-time batch table with mode badges (*Live Online*, *Hybrid*, *Classroom*), remaining seat counters, and one-click demo/booking triggers.

### 7. Instant Syllabus Generation Engine (`CourseDetailsPage.tsx`)
- Real-time browser-side generation of comprehensive syllabus text files with module breakdowns, lab assignments, and prerequisites for all courses.

### 8. Full-Featured Admin Portal & CRM (`AdminPortalPage.tsx`)
- Role-secured admin portal to manage 9 incoming lead streams, update enquiry status (*NEW*, *CONTACTED*, *QUALIFIED*, *PROPOSAL_SENT*, *ENROLLED*, *CLOSED*), export CRM records to CSV, and publish new upcoming batches.

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Vite 8, Tailwind CSS 3.4, React Router DOM 7, Lucide Icons, Canvas Confetti.
- **Backend**: Node.js v22, Express.js, Prisma ORM 5.22, PostgreSQL, Helmet, CORS, Zod, bcryptjs, jsonwebtoken.
- **Dual-Mode API Layer**: Features automatic fallback between live Express REST endpoints and browser `localStorage` to guarantee 100% uptime and offline testability.

## 💻 Local Development Setup

### 1. Prerequisites
- **Node.js** v20+ (tested on v22.17.0)
- **npm** v10+

### 2. Frontend Setup & Launch
```powershell
# Navigate to project directory
cd C:\Users\sunda\.gemini\antigravity\scratch\nodalbot-technologies

# Start Vite development server
npm run dev
```
The frontend will start at `http://localhost:5173`.

To create an optimized production build:
```powershell
npm run build
npm run preview
```

### 3. Backend Setup & Launch (Optional / API Mode)
```powershell
cd C:\Users\sunda\.gemini\antigravity\scratch\nodalbot-technologies\server

# Start backend server
npm run dev
# Or run compiled production server:
node dist/index.js
```
The Express API runs at `http://localhost:5000` with health check at `http://localhost:5000/health`.
